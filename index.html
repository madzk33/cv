01

Shift Handover AI

Shift notes at a food production site were losing information between handovers. Built the pipeline that fixes it, in a single day.

  • Claude Code
  • Llama 3.3 70B on Groq
  • Whisper
  • Pydantic v2
  • SQLite

Read the detailHide the detail

The problem
Handover notes were written freehand at the end of long shifts. Half-finished jobs and equipment behaving oddly went missing in the gaps between one team leaving and the next arriving.
What I built
Typed or spoken input, Whisper handles voice, gets structured by an LLM into six fixed categories, then checked against a strict Pydantic v2 schema before anything is accepted. Exports to Markdown and Slack-ready text. Full history logged to SQLite.
The part I got wrong first
My first pass let the model fill in gaps it wasn't sure about. It took one shift report with a plausible but wrong maintenance note to convince me that was the wrong default. Now anything genuinely ambiguous gets recorded as "unspecified" instead.

03 / method

How I work with AI

Claude Code is where I write production code, not where I generate snippets I then rewrite. Most of what I hand it doesn't have a known shape yet, so the actual work is framing the problem clearly enough that I can judge whether what comes back is right.

The Pydantic schema in Shift Handover AI is the clearest example of how I treat its output: check it at the boundary, the same as I'd check any input I didn't write myself. A plausible wrong answer costs more than a visible gap, so that's what the system is built to prefer.

The harder skill is knowing when not to reach for it. If I can't describe what a correct answer looks like, generating one doesn't save me anything.

This page is proof of the method, not just a description of it: built end to end in Claude Code, including the parts that took several passes to get right.

shift_entry.py
VALID = {"ok", "issue"}
 
class ShiftEntry(BaseModel):
    status: Literal[
        "ok", "issue",
        "unspecified"
    ]
    notes: str
 
    @field_validator(
        "status", mode="before"
    )
    def reject_guess(cls, v):
        # no guessing
        if v not in VALID:
            return "unspecified"
        return v

The actual validator behind "Shift Handover AI." A wrong guess never ships quietly.
